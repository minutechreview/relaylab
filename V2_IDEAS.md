# RelayLab V2 ideas

These ideas are deliberately excluded from the WebMCP Challenge MVP. This file is a parking lot, not a Phase 1–7 backlog. None of these features should be implemented before the frozen v1 scope is complete and reliable.

## Editing features intentionally deferred

- Transitions between the base video and B-roll.
- Color/colour correction and grading.
- Animation keyframes.
- Multiple B-roll overlay tracks.
- Multiple talking-head/base tracks.
- Arbitrary clip trimming or destructive source edits.
- A general-purpose multi-track NLE.
- Premiere Pro, Final Cut, DaVinci Resolve, or CapCut clone functionality.
- Effects, filters, compositing modes, masks, and chroma keying.
- Picture-in-picture layout controls beyond the focused v1 overlay behavior.
- Motion graphics authoring.
- A motion graphics template marketplace.
- Title cards and a caption design studio.
- Rich typography, per-word caption animation, and caption themes.
- Advanced scene/shot editing.
- Frame-perfect professional NLE precision.
- Cross-browser render parity beyond the Chrome-priority MVP.

## Audio intentionally deferred

- B-roll volume controls.
- Enabling or unmuting B-roll audio.
- Audio mixing.
- Multiple audio tracks.
- Background music.
- Sound effects.
- Voice-over recording.
- Audio ducking, normalization, noise reduction, or mastering.
- Beat detection and beat-synchronized editing.

The v1 invariant remains: the locked base video's audio is the only audio source.

## Content sourcing and broader generation intentionally deferred

- Stock footage search or licensing integrations.
- Automatic or agent-initiated generative video. V1 permits only a single-purpose, human-clicked fal.ai fallback after the uploaded library has no strong match.
- Generative images.
- General text-to-video or image-to-video workflows beyond the bounded V1 fallback.
- Automated motion graphics generation.
- AI avatars or synthetic presenters.
- Web crawling for media.
- Public asset marketplaces.

## Product and collaboration intentionally deferred

- Login and authentication.
- User profiles.
- Billing, subscriptions, and usage metering.
- Teams and organizations.
- Roles and permissions beyond the local human/agent trust boundary.
- Comments, review threads, and annotations.
- Real-time multiplayer editing.
- Shareable review links.
- Cloud project management.
- Cloud media storage and transcoding.
- Cross-device project synchronization.
- Version history and project branching.
- Reusable organization libraries.
- Mobile or tablet editor.
- Native desktop or mobile applications.

## Advanced agent ideas intentionally deferred

- Giving the agent access to every UI command.
- Agent-controlled plan approval.
- Agent-controlled human locks.
- Agent access to base-audio mixing or replacement.
- Autonomous publishing.
- Multi-agent editorial rooms.
- Persistent personalized editing-style learning.
- Automatic final-cut generation without human review.
- Browser automation, screenshot reasoning, DOM clicking, or coordinate control as an editing interface.
- Large unbounded tool surfaces mirroring every UI button.
- Vector-database infrastructure before simple metadata search proves insufficient.

## Advanced analysis intentionally deferred

- Full-frame, full-duration video understanding.
- Continuous vision inference during editing.
- Repeated vision calls for already-indexed media.
- Speaker diarization and multi-speaker editorial logic.
- Emotion or sentiment-driven editing.
- Face recognition or identity databases.
- Object tracking and motion paths.
- Optical flow and camera-motion analysis.
- Automated continuity checking.
- Copyright, brand-safety, or legal-clearance automation.
- Large-scale cloud indexing of media libraries.

## Export and delivery intentionally deferred

- Server-side render farms.
- Distributed or queued transcoding.
- 4K/8K production guarantees.
- Hardware-accelerated cross-platform export tuning.
- Professional codec and color pipeline management.
- Multiple aspect-ratio variants.
- Social-platform publishing integrations.
- YouTube, TikTok, Instagram, or podcast distribution.
- Project interchange with Premiere, Resolve, Final Cut, or CapCut.
- EDL, XML, AAF, and advanced interchange formats.
- Cloud-hosted rendered deliverables.

## Possible post-challenge explorations

Only after the MVP is proven, useful next experiments may include:

- richer but still replaceable semantic B-roll retrieval;
- reusable editorial pacing profiles;
- optional multiple video-only overlay lanes;
- constrained transition presets;
- server-side rendering for longer projects;
- safe project persistence; and
- export interchange with an established NLE.

Each would need a new scope decision, trust-model review, and evidence that it improves the focused human/agent collaboration thesis.
